# Agent Workspace

Protocol version: 2

This directory stores durable coordination records for this repository.
Authoritative open work is in `tasks/` and its referenced permanent plan in
`plans/`. `active.md` and `PLANS.md` are derived indexes.

The existing `archived/` and `v1.2.0/` directories are preserved legacy records.
They have not been rewritten or upgraded to protocol-v2 claims.
