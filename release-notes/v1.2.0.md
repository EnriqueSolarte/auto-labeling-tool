# v1.2.0 Release Notes

## Highlights

- Added `auto-label-tool visualize-mask -c <config>` to inspect existing
  aggregated masks without rerunning aggregation.
- The mask viewer supports direct and per-episode `average_mask` layouts and
  overlays masks on matching RGB frames when available.
- File creation now prefers hard links. If a hard link or symlink cannot be
  created, the tool asks before using the next fallback.
- Added durable repository task and plan coordination records.

## Upgrade note

Configuration files include an exact package-version value. After upgrading from
v1.1.0, regenerate the config with `auto-label-tool create-config`, or update
its top-level `version` field to `v1.2.0` after reviewing the configuration.

## Known limitations

`visualize-mask` requires a graphical OpenCV display. No branch, tag, or package
is pushed or published by this release preparation.
